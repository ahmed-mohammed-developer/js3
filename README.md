  # 🖼️ Image Gallery & Lightbox

معرض صور تفاعلي يتيح للمستخدم استعراض الصور المصغّرة وفتحها بحجم أكبر من خلال نافذة عرض (Lightbox)، مع إمكانية التنقل بين الصور باستخدام الأزرار أو لوحة المفاتيح.

تم تطوير المشروع باستخدام HTML وCSS وJavaScript، مع التركيز على التصميم المتجاوب، سهولة الاستخدام، وإمكانية الوصول (Accessibility).

## ✨ Features

- عرض الصور ضمن شبكة متجاوبة باستخدام CSS Grid.
- تكبير الصور داخل نافذة Lightbox.
- التنقل بين الصور السابقة والتالية.
- عرض وصف الصورة والعداد الحالي للصور.
- إغلاق النافذة باستخدام زر الإغلاق أو مفتاح `Escape`.
- إغلاق النافذة عند الضغط على الخلفية خارج الصورة.
- دعم التنقل باستخدام أسهم لوحة المفاتيح.
- إدارة التركيز وإعادته إلى الصورة الأصلية بعد إغلاق النافذة.
- منع تمرير الصفحة أثناء فتح النافذة.
- دعم إعدادات تقليل الحركة `prefers-reduced-motion`.
- مراعاة مبادئ إمكانية الوصول (Accessibility).
- تصميم متجاوب مع مختلف أحجام الشاشات.

## 🛠️ Technologies Used

- **HTML5** — لبناء هيكل الصفحة.
- **CSS3** — لتنسيق الواجهة وإنشاء التصميم المتجاوب والتأثيرات.
- **JavaScript (Vanilla JS)** — لإضافة التفاعلات وإدارة نافذة الصور.

## 🚀 Getting Started

1. انسخ المستودع إلى جهازك:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. انتقل إلى مجلد المشروع:

   ```bash
   cd image-gallery
   ```

3. افتح ملف `index.html` في المتصفح، أو شغّل المشروع باستخدام إضافة Live Server في Visual Studio Code.

## ♿ Accessibility

يراعي المشروع عددًا من ممارسات إمكانية الوصول، منها:

- استخدام النصوص البديلة للصور عبر `alt`.
- إضافة تسميات واضحة للأزرار.
- دعم التفاعل باستخدام لوحة المفاتيح.
- استخدام عنصر HTML الأصلي `<dialog>` لعرض نافذة الصور.
- الاهتمام بإدارة التركيز أثناء فتح النافذة وإغلاقها.

## 🎯 Project Goal

يهدف المشروع إلى تطبيق مفاهيم HTML وCSS وJavaScript عمليًا، وبناء مكوّن واجهة مستخدم تفاعلي يجمع بين التصميم المتجاوب وإمكانية الوصول وسهولة الاستخدام.
